# compiler: the Ergo compiler written in Ergo

`compiler/` is the top-level Ergo module (`module compiler`) of the self-hosted compiler (capstone S1 to S6). Its first packages are the formatter of the self-hosting pilot (SH0, SH1), moved here at S1a. Since S1c the formatter is the product: the Go formatter (`internal/sketch/format`) is deleted, `internal/hostsyntax` is its Go facade, and the seed's `ergo fmt` is the oracle (`TestFormatAgreesWithSeed`; a change since the seed is a row of `CHANGES-since-seed.md`).

The binary holds these packages through `internal/linked` (`docs/tooling.md`, Linked Ergo packages): the one row `compiler` of `linked.Packages` lowers `compiler/api` through the IR into `internal/linked/compiler/compiler.go`, and Go calls it. Since S2d every Go caller of `syntax.Parse` parses with it: `internal/sketch/syntax` decodes the rows into its AST. Since S1d the formatter and the parse dumps are one linked package, so the binary links compiler/syntax once. Since S2c the formatter parses in Ergo and reads the rows itself: `internal/hostsyntax.Source` hands it the source and reads back the text.

## Layout

- `format/` (pure): the formatter rewritten from `internal/sketch/format`, typed over `syntax.Parsed`. `format.ergo` holds the contract (`Layouter` with its laws), the failures (`SyntaxFailure`, `OutputLimit`) and the entry `Source` (parse with `compiler/syntax`, print); `printer.ergo` and `nodes.ergo` print each node kind through the view's readers; `span.ergo` gives each row's first and last token, the precedences and the line-break rules; `layout.ergo` is the line/cell state and its pure transition over the closed `Command` union; `comments.ergo`, `align.ergo` (column sections, render, the size limit decided before any text is built) and `text.ergo` (byte and rune helpers); `laws.ergo` checks Idempotent, ShapeKept, CommentsKept and Bounded on a source, parsing both sides in Ergo.
- `api/` (pure): the linked package's root, primitive in and out. `FormatSource(src, limit)` is the formatter's outcome; `Laws(src)` the source laws; `Steps(commands, limit)` the layout state's outcome. `dump.ergo` passes `syntax/dump`'s entries through (`Scan`, `Parse`, `Columns`, `Tokens`, `Failure`).
- `syntax/` (pure): the scanner and parser on SELFLAYOUT's layout (capstone S2a, S2b), moved here from their run dirs. The scanner writes token columns (`token.ergo`: a one-byte kind and a start, `End` by a second scan; `scan.ergo`: dispatch on the first byte, keywords by length and compare), `comments.ergo` and `lines.ergo`; the parser (`parse*.ergo`, `diag.ergo`) writes `Tree`, 13-byte rows with one `extra` pool (`tree.ergo`), and `view.ergo` reads a row as the closed unions `Expr`, `Stmt`, `Decl`, `Type` and writes one back (`View`, `Put`). `skip "reason"` is a statement only before a string literal: `skip` is no scanner keyword. Each law sits beside the declaration it is about (S115): the scanner's in `scan.ergo` and `diag.ergo`, the tree's in `parse.ergo`. `columns.ergo` packs a parse into one `[]uint32` (header, token columns, rows, `extra`, comments, groups) for a host to read.
- `syntax/dump/` (pure): `Scan(src)` and `Parse(src)`, the canonical dumps of one scan and one parse (the parse through the view), and `Columns(src)` and `Failure(src)`, the packed parse and its failure. `compiler/api` passes them through to the linked package `internal/linked/compiler`, which `syntax.Parse` reads since S2d: `internal/sketch/syntax/decode.go` (`ParseRows`) builds the Go nodes from `Columns`, every field the Go parser set, and `TestDecodeAgreesWithView` compares their dump with `Parse`'s. With the Go parser deleted (S2e), `TestFormatParseRoundTrip` and `TestFormatIsTheCorpusFixpoint` hold the parser to the formatter.
- `ir/` (pure): the IR of capstone S4. A function's body is rows (`ir.ergo`: `Body`'s columns, a one-byte kind, two words a and b, the position, one extra pool); `kinds.ergo` is the kind table (49 kinds from S4b's census, each with the slots it sets, in the Go type's field order) and `Slot`; `build.ergo`'s `Builder` adds rows children first (`Begin`, `Row`, `List`, `PosAt`, `End`, `Finish`), interning texts and files; `json.ergo`'s `Write` is the IR file byte for byte as the Go IR builder writes it with encoding/json (`Quote` with Go 1.27's escapes). `compiler/api`'s `IRWrite` replays into the `Builder` the nodes a Go host sends and `IRKinds` gives the host the table; `TestIRWriteAgreesWithGo` (internal/selfhostcheck) compares the text with the Go builder's file on every example and on seeded files, and refuses a kind or field the table lacks.
- `check/store/` (pure): the self-hosted checker's tables (capstone S3a): id spaces, object tables, the package scope, the type pool, the declarations with their fingerprints (`Prints`: `Fp` over a declaration's tokens, `Ifp` over what an importer sees), each file with its laws.
- `check/bind/` (pure): collect and bind on the store (capstone S3b). `collect.ergo` puts each file's package-level declarations into the store; `parents.ergo` is the parent column over the package's rows (`PNode` = file base + row), with each row's children; `bodies.ergo` resolves every identifier (`Uses`) and marks the body's declarations (locals and laws) on one undo stack (`dense.Stack`), as body tasks (capstone S3c: `Bind` cuts the top-level rows into pieces, runs them through `tasks.Transform`, each into its own `Body` with a names overlay, and `Join` merges them in row order, so the result is the same at any thread count, law `JoinIsThreadFree`); `prints.ergo` gives each declaration its prints. `internal/selfhostcheck`'s `TestCompilerBindAgreesWithChecker` holds Uses and Defs equal to the Go checker's over the corpus.
- `check/types/` (pure): the kinds of bracket parameters and the types of declarations, on the store (capstone S3t). `kinds.ergo` solves each generic type's parameter kinds (type, error row, capability row) by union-find over positions, links through local generic types and the receiver rule (196m); `resolve.ergo` resolves a type expression to a pool type and prints it as the Go checker's `Type.String`; `records.ergo` lists the record declarations (inline variants included), the defined types and the refined types (each derives its `ParseN`). `SolveFuncKinds` gives function declarations' bracket parameters their kinds; `Resolve` of a function declaration's type is its signature, with a union in a row standing for its variants and `wired[P]` of a bracket parameter (`wired[T]` of a concrete `T` is not resolved yet). Other packages' types come in as a table until S3c's frozen interfaces. `check/store/types_api.ergo` is S3t's addition to the store: the pointer, tuple, signature, array and foreign kinds, the own and entry marks, and readers; `check/store/types_rows.ergo` adds the row value (`A | B` as a type argument) and `wired[P]`. `TestCompilerTypesAgreeWithChecker` and `TestCompilerTypesProperty` hold the kinds, the record field types, the defined types' bases and the function signatures equal to the Go checker's.
- `cmd/typedump`: prints the resolved record field types, defined types and signatures of the named files, or with `-kinds` the solved kinds (types and functions); `-std DIR` loads the imports, whose types are XRefs into each import's `types.Iface` (`check/types/program.ergo`). The agreement tests' dump.
- `check/task/` (pure): package tasks (capstone S3c2). `Check` runs a program's packages in waves, a package once every package it imports has frozen its store (`store.Freeze`, the interface importers read with no lock), each wave's packages as tasks; a selector into an import resolves to an `XRef` (the import's place in the sorted import list plus one, and its `Decl`). Laws `ImportsNameTheirDeclarations`, `ProgramIsThreadFree`.
- `check/infer/` (pure): type-argument inference (capstone S3d1, C0/plan.md §2.6). An inference is a frame of slots on a scratch stack, one per type parameter of the callee, found by position (the callee's parameters renamed past the caller's in the pool); `Unify` follows the Go checker's unify.go on the pool's ids (rows by the row-union rule, a result parameter against no result is no value); `Infer` is callGeneric's order (typed arguments, then literals' common default, then empty rows). Laws `InferRecoversBindings`, `InferRejectsMismatches`, `FramesNest`, `InferStepsPerCallAreConstant`.
- `check/expr/` (pure): expression types (capstone S3d). `Load` reads a package's function, law and test signatures and record fields through check/types; `Check` walks each body in source order and gives each expression it can type its pool type, as the Go checker's `Info.Types` does: locals by their declarations, constants by their context, calls (a generic one through check/infer on its arguments' types), composite literals, record fields, function literals whose rows are known, as-patterns and addresses. An expression it cannot type yet (an import's member, a method) is left untyped. `TestCompilerExprAgreesWithChecker` holds every typed expression and inferred call equal to the Go checker's and logs the reach by form.
- `cmd/exprdump`: prints check/expr's typed expressions (`FILE START END TYPE`) or, with `-calls`, its inferred generic calls, the expression agreement's dump.
- `cmd/inferdump`: prints the type arguments check/infer infers for a package's calls to its own generic functions whose arguments are literals or the caller's parameters, the inference agreement's dump.
- `lower/` (pure): the IR builder of capstone S4 (S4c), ported from the Go builder slice by slice. `Package` builds each function of a checked package (the store, bind's uses, check/expr's types) into an `ir.File` through `ir.Builder`, or stops at it with a cause: an expression check/expr left untyped, or a form or decider not ported yet. S4c2 builds leaf bodies (a pure function of basic parameters and result whose body is one tail expression of parameters, literals and operators).
- `cmd/irdump`: builds the IR of each package of exprdump's corpus manifest with `lower` and prints the IR file's paths (`P`), each built function's IR (`F`, `ir.WriteFunc`) and each stop with its cause (`S`); the Ergo side of `TestCompilerIRAgreesWithBuilder`, which compares each built function with the Go builder's at the same declaration and logs the reach by cause.
- `cmd/binddump`: prints bind's declarations, uses (`-uses`), declarations with locals (`-locals`) or locals' name ids (`-names`) of the named files, the agreement test's dump; `-threads N` binds on up to N tasks; `-std DIR` loads the imports (the module's folders, its go.mod's local replaces, then DIR).
- `cmd/parsedump`, `cmd/scandump`: print the dumps of the named files, one `F path` line before each, and with `-n` the counts the receipts use.

## Run

```sh
ergo check compiler/api
ergo test compiler/format
ergo test compiler/syntax
ergo test compiler/check/store
ergo test compiler/check/bind
ergo test compiler/check/task
ergo test compiler/check/types
ergo test compiler/check/infer
ergo check compiler/check/expr
ERGO_TEST_CLI=bin/ergo go test -count=1 -run '^TestCompiler(Store|Bind|Task|Types|Infer|Expr)' ./internal/selfhostcheck
go test -count=1 -run '^Test(DecodeAgreesWithView|FormatParseRoundTrip|FormatIsTheCorpusFixpoint)$' ./internal/sketch/syntax
ERGO_SELFHOST_SEED=1 go test -count=1 -run '^Test(SelfhostFormatLaws|FormatAgreesWithSeed|SelfhostLayoutModel)$' ./internal/selfhostcheck
go run ./scripts/linked
```
