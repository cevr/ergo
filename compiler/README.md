# compiler: the Ergo compiler written in Ergo

`compiler/` is the top-level Ergo module (`module compiler`) of the self-hosted compiler (capstone S1 to S6). Its first packages are the formatter of the self-hosting pilot (SH0, SH1), moved here at S1a. Since S1c the formatter is the product: the Go formatter (`internal/sketch/format`) is deleted, `internal/hostsyntax` is its Go facade, and the seed's `ergo fmt` is the oracle (`TestFormatAgreesWithSeed`; a change since the seed is a row of `CHANGES-since-seed.md`).

The binary holds these packages through `internal/linked` (`docs/tooling.md`, Linked Ergo packages): the one row `compiler` of `linked.Packages` lowers `compiler/api` through the IR into `internal/linked/compiler/compiler.go`, and Go calls it. Since S2d every Go caller of `syntax.Parse` parses with it: `internal/sketch/syntax` decodes the rows into its AST. Since S1d the formatter and the parse dumps are one linked package, so the binary links compiler/syntax once. Since S2c the formatter parses in Ergo and reads the rows itself: `internal/hostsyntax.Source` hands it the source and reads back the text.

## Layout

- `format/` (pure): the formatter rewritten from `internal/sketch/format`, typed over `syntax.Parsed`. `format.ergo` holds the contract (`Layouter` with its laws), the failures (`SyntaxFailure`, `OutputLimit`) and the entry `Source` (parse with `compiler/syntax`, print); `printer.ergo` and `nodes.ergo` print each node kind through the view's readers; `span.ergo` gives each row's first and last token, the precedences and the line-break rules; `layout.ergo` is the line/cell state and its pure transition over the closed `Command` union; `comments.ergo`, `align.ergo` (column sections, render, the size limit decided before any text is built) and `text.ergo` (byte and rune helpers); `laws.ergo` checks Idempotent, ShapeKept, CommentsKept and Bounded on a source, parsing both sides in Ergo.
- `api/` (pure): the linked package's root, primitive in and out. `FormatSource(src, limit)` is the formatter's outcome; `Laws(src)` the source laws; `Steps(commands, limit)` the layout state's outcome. `dump.ergo` passes `syntax/dump`'s entries through (`Scan`, `Parse`, `Columns`, `Tokens`, `Failure`).
- `syntax/` (pure): the scanner and parser on SELFLAYOUT's layout (capstone S2a, S2b), moved here from their run dirs. The scanner writes token columns (`token.ergo`: a one-byte kind and a start, `End` by a second scan; `scan.ergo`: dispatch on the first byte, keywords by length and compare), `comments.ergo` and `lines.ergo`; the parser (`parse*.ergo`, `diag.ergo`) writes `Tree`, 13-byte rows with one `extra` pool (`tree.ergo`), and `view.ergo` reads a row as the closed unions `Expr`, `Stmt`, `Decl`, `Type` and writes one back (`View`, `Put`). `skip "reason"` is a statement only before a string literal: `skip` is no scanner keyword. The laws are in `scan_laws.ergo` and `tree_laws.ergo`. `columns.ergo` packs a parse into one `[]uint32` (header, token columns, rows, `extra`, comments, groups) for a host to read.
- `syntax/dump/` (pure): `Scan(src)` and `Parse(src)`, the canonical dumps of one scan and one parse (the parse through the view), and `Columns(src)` and `Failure(src)`, the packed parse and its failure. `compiler/api` passes them through to the linked package `internal/linked/compiler`, which `syntax.Parse` reads since S2d: `internal/sketch/syntax/decode.go` (`ParseRows`) builds the Go nodes from `Columns`, every field the Go parser set, and `TestDecodeAgreesWithView` compares their dump with `Parse`'s. With the Go parser deleted (S2e), `TestFormatParseRoundTrip` and `TestFormatIsTheCorpusFixpoint` hold the parser to the formatter.
- `ir/` (pure): the IR of capstone S4. A function's body is rows (`ir.ergo`: `Body`'s columns, a one-byte kind, two words a and b, the position, one extra pool); `kinds.ergo` is the kind table (49 kinds from S4b's census, each with the slots it sets, in the Go type's field order) and `Slot`; `build.ergo`'s `Builder` adds rows children first (`Begin`, `Row`, `List`, `PosAt`, `End`, `Finish`), interning texts and files; `json.ergo`'s `Write` is the IR file byte for byte as the Go IR builder writes it with encoding/json (`Quote` with Go 1.27's escapes). `compiler/api`'s `IRWrite` replays into the `Builder` the nodes a Go host sends and `IRKinds` gives the host the table; `TestIRWriteAgreesWithGo` (internal/selfhostcheck) compares the text with the Go builder's file on every example and on seeded files, and refuses a kind or field the table lacks.
- `cmd/parsedump`, `cmd/scandump`: print the dumps of the named files, one `F path` line before each, and with `-n` the counts the receipts use.

## Run

```sh
ergo check compiler/api
ergo test compiler/format
ergo test compiler/syntax
go test -count=1 -run '^Test(DecodeAgreesWithView|FormatParseRoundTrip|FormatIsTheCorpusFixpoint)$' ./internal/sketch/syntax
ERGO_SELFHOST_SEED=1 go test -count=1 -run '^Test(SelfhostFormatLaws|FormatAgreesWithSeed|SelfhostLayoutModel)$' ./internal/selfhostcheck
go run ./scripts/linked
```
